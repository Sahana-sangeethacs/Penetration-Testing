# Documents which are to be collected for pre-engagement
1. NDA (non-disclosure agreement) 
 - which refers to the legal agreement signed by both the involved parties and any other third parties to keep certain information confidential
2. Scoping Questionnaire
 - A set of questions which are asked ahead the penetration testing as in to understand the service the client is seeking for and to make 
 sure how much of an access we have within the system/network
3. Scoping Document
 - This refers to the boundaries set within the system as in what targets are to be tested, systems that are not included, Testing time and the 
 limitations included 
4. Contract/Scope of work(SoW)
 - This document refers to the work that will be done by the pentester during the entire process which includes the responsibilities, process and 
 what would be delivered after the pentration testing 
5. Rules of Engagement (RoE)
 - This document refers to the set of rules that are to be followed when within the network/system during the process of pentesting
6. Contractors Agreement(Physical)
 - This refers to the agreement between the two parties for physical security testing as in accessing the physical asssets of the corporate network
 or the company
7. Authorization For Testing
 - This document refers to the official permission to conduct the penetration testing on the agreed parties which confirms that the organization has 
 authorized for testing
