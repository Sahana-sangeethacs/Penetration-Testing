# Penetration-Testing
This repository is to document my journey on learning about penetration testing, with a focus on practical, hands-on learning through Hack The Box Academy, labs, exercises, and personal practice.
Focusing on understanding how penetration testers think, investigate, exploit, and document security weaknesses.
 
I'm currently focusing on:
Linux fundamentals for penetration testing,
Networking fundamentals,
Reconnaissance,
Enumeration,
Vulnerability identification,
Web application security,
Exploitation,
Privilege escalation,
Active Directory,
Pentesting methodology,
Writing clear technical notes and reports,

  My long term goal is to develop the practical skills required to perform professional penetration tests and eventually build a strong cybersecurity portfolio.
I will continuously update this repository as I progress through my penetration-testing training.
